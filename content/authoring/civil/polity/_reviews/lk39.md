## HIGH
**H1 - CS-POL-ch39-017 (LK-39.1 q17, "how many"), statement 2: two defensible answers.**
"The Dantwala Committee (1978) suggested that the basic decentralised planning function be done at the block level."
The key counts it as false because the book (p.552) says "Both the committees [Dantwala, Hanumantha Rao] have suggested that
the basic decentralised planning function should be done at the district level". But the same sentence names the
Dantwala report as the "Report on **Block-Level Planning** (1978)", and in real history the Dantwala Committee did
recommend the block as the planning unit. A student who knows the real fact marks statement 2 correct, gets three correct
statements (2, 3, 4) and picks "Only three statements", which is a different option from the key ("Only two"). This is the
recurring defect: a statement false only because the book words it differently. Fix: delete statement 2 and use an
unambiguous false one, for example "The G.V.K. Rao Committee recommended that the Collector be the chairman of the Zila
Parishad" (p.552 says it recommended reducing the Collector's role), or drop the Dantwala name and keep the
Hanumantha Rao fact only. Update the explanation, which currently asserts the book's reading as fact.
