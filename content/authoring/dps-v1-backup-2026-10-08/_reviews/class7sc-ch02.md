## HIGH (wrong or unsupported key, key contradicting the display)

1. C7SC-2.3 #9, #11, #19, #21 (match "Onion strip with baking soda solution ... Smell disappears / Smell stays"; "(b) What happens to the smell when baking soda solution falls on one strip and tamarind water on another?"; "Describe the onion activity ... what you observe"; case study Pooja "The onion smell disappears from the second strip ... What is the nature of X?"). The book's Activity 2.6 (p.16) never states the result: it only asks "Do you notice any change in the odour". No page says the onion smell vanishes in a base and stays in an acid. The keys, three of the case-study parts (b), (c), (d) and the whole 5-mark answer rest on a fact this textbook does not give (QUESTION_STANDARD s11: "Do not claim more than the book does"). A student who did the activity as the book instructs cannot be marked from the book. Smallest fix: either rewrite these so the stem states the observation ("the onion smell vanished when X was added; what does this say about X?" is still unsupported, so better to state it as given data and ask only the olfactory-indicator definition and the base/acid reasoning that follows), or drop the result-dependent parts and test only the definition (#2 stays, it is sound). The 5-mark #18 should become a different item (see Medium).
2. Answer text "Option (a)" / "Option (b)" in the assertion-reason keys: C7SC-2.1 #8 ("Option (b)"), 2.2 #8, 2.3 #8, 2.4 #8 ("Option (a)"), 2.5 #8 ("Option (a)") and 2.5 #9 ("Option (b)"). The loader shuffles all four options of every option-type item (shuffled(q.o...) with relabel A-D), so the shown letters will not match the "(a)/(b)" in the key text, and the AR options also lose the standard order. Student sees key "Option (b)" next to a displayed option C. Smallest fix: remove the "Option (x)" sentence from every AR answer and say only "Both true; R does/does not explain A".
3. C7SC-2.5 #18 (5-mark "Name three situations from the chapter where neutralisation is used"). Steps award one mark each to FOUR situations plus one for the "common idea" (5 marks), but the question asks for three. A student giving the three requested can earn at most 4/5. Fix: ask for "four situations" (or change steps to "any three situations, 1 mark each", 2 marks for the reasons).
4. C7SC-2.4 #21 (case study Sanjana: vinegar + baking soda solution, thermometer 28 to 31 degrees C). This is a fact error in real chemistry: baking soda with vinegar releases CO2 and the mixture gets slightly colder (net endothermic), so a 3-degree rise is not what a student would measure and a teacher would object. The book's own sentence (heat is released in neutralisation) is still the intended idea. Fix: use vinegar with lime water, or lemon juice with lime water (the book's pair), with the same data. The arithmetic itself (31 - 28 = 3) is correct.

Breaks the anti-template rule (false statement spread 1/2/3; keyed combination varied). Fix: rewrite three of them so the false statement is 1 or 3, and key "2 and 3 only", "1 only", "all three" etc.

Agree?" with the limited-case reason), and one partly right.
