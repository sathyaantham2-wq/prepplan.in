## MEDIUM
1. C9S-1.4#16 (assertion_reason): A (carbon-14 and genetics establish timelines) and R (modern historiography relies on empirical evidence) are both true, keyed "R explains A". The book only says historiography "relies on empirical evidence and uses tools such as..."; A is an instance of R, so "true but not the explanation" is also defensible. Rework R so the link is unambiguous, or change the intended outcome.
2. C9S-1.3#13 (long): key assigns disciplines to the drought effects (culture -> History, society left unassigned). The book lists the effects but never matches them to disciplines; this is inference presented as chapter content in a 2-mark rubric line. Make the marking accept any reasoned match, or ask only for aspects.
3. Easy-in-disguise MCQs: 1.1#3, 1.1#4, 1.1#6, 1.2#13, 1.4#11, 1.4#18, 1.5#7, 1.6#4, 1.6#8, 1.6#14, 1.6#15. Several wrong options are strawmen not real confusions (1.6#15, 1.6#8, 1.6#14). Fix by making wrong options look-alike chapter terms.
4. Strawman case: C9S-1.6#13 (coastal village). Embankment is cheaper per household and protects all 300; relocation protects only 120 yet is costed per household protected, and the key invents "keeps all at risk if it fails to hold". Trade-off is lopsided. Also 1.5#1: Plan A wins on every number; only the equity argument supports B.
