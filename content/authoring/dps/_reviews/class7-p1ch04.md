## HIGH (1)

1. **C7M-4.1, multi_statement, Shabnam (s) and Aftab (a).** "Statement 1: The expression for Shabnam's age can be written only with the letters a and s." Under the natural reading this is TRUE: s, and a + 3, both use only letters from {a, s}. Then 1, 2 and 3 are all correct, which is not an option, so the item has no correct answer. The key (2 and 3 only) relies on a reading the sentence does not support. Fix: replace Statement 1 with an unambiguous false one, for example "Shabnam's age cannot be written using the letter a" (false, it is a + 3), keeping the key "2 and 3 only".
